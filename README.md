# BSERC Week 1 Project 2 — Interactive HTML Pages

Five standalone interactive demos created for the BSERC Week 1 Project 2. Explore CSE study support, AI/ML concepts, AI safety, agent systems, and ML systems.

## Live demos

[Open the demo gallery](https://smirzaa36.github.io/bserc-project-2-html-pages/)

- [CSE Panic Room](https://smirzaa36.github.io/bserc-project-2-html-pages/cse-panic-room.html) — revision missions, focus sprint, concept cards, and viva quiz.
- [Neural Network 3D Model](https://smirzaa36.github.io/bserc-project-2-html-pages/neural-network-3d-model.html) — explore network layers, architectures, inputs, and an illustrative forward pass.
- [Agent Autonomy Arena](https://smirzaa36.github.io/bserc-project-2-html-pages/agent-autonomy-arena.html) — compare fictional agent profiles, permissions, and guardrails.
- [Prompt Injection Escape Room](https://smirzaa36.github.io/bserc-project-2-html-pages/prompt-injection-escape-room.html) — practice identifying untrusted instructions in fictional scenarios.
- [GPU Detective](https://smirzaa36.github.io/bserc-project-2-html-pages/gpu-detective.html) — explore illustrative training-memory estimates and configuration trade-offs.

## Run locally

Open any HTML file in a current browser. The pages are self-contained and designed to work offline.

## Project notes

- Each demo includes a Light/Dark theme switch and responsive layout.
- Agent scores, GPU figures, and training behavior are classroom simulations, not real evaluations, benchmarks, or model training.
- The escape-room scenarios are fictional. The pages do not connect to services or send data. The CSE Panic Room saves study progress in local browser storage on the device.
- [prompts.txt](prompts.txt) includes the build prompts, refinement prompts, and an effort-comparison note.
