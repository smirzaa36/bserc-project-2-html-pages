# BSERC Week 1 Project 2 — Interactive HTML Pages

A set of five standalone, interactive HTML learning tools created for the BSERC Week 1 Project 2. The pages focus on CSE study support, AI/ML concepts, AI safety, and ML systems.

## Pages

| Demo | Description |
| --- | --- |
| [CSE Panic Room](cse-panic-room.html) | Study dashboard with revision missions, focus sprint, concept cards, and viva quiz. |
| [Neural Network 3D Model](neural-network-3d-model.html) | Explore network structure, architectures, inputs, and an illustrative forward pass. |
| [Agent Autonomy Arena](agent-autonomy-arena.html) | Compare fictional agent profiles across missions, priorities, permissions, and guardrails. |
| [Prompt Injection Escape Room](prompt-injection-escape-room.html) | Practice identifying untrusted instructions in fictional AI-safety scenarios. |
| [GPU Detective](gpu-detective.html) | Explore illustrative training-memory estimates and possible configuration changes. |

## Run locally

Download or clone this repository, then open any HTML file in a current browser. The pages are self-contained and designed to work offline.

## Project notes

- Each demo includes a Light/Dark theme switch and responsive layout.
- Agent scores, GPU figures, and training behavior are classroom simulations, not real evaluations, benchmarks, or model training.
- The escape-room scenarios are fictional. The pages do not connect to services or send data. The CSE Panic Room saves study progress in local browser storage on the device.
- [prompts.txt](prompts.txt) contains the build prompts, refinement prompts, and an effort-comparison note.
