# BSERC Week 1 Project 2 — Interactive HTML Pages

This project contains five standalone interactive HTML pages created for BSERC Week 1 Project 2. It covers a revision dashboard, an interactive 3D model, a decision helper, and two original AI/ML ideas. Each page has five or more interactive controls, a responsive layout, and a Light/Dark theme switch.

## Live demos

[Open the demo gallery](https://smirzaa36.github.io/bserc-project-2-html-pages/)

- [CSE Panic Room](https://smirzaa36.github.io/bserc-project-2-html-pages/cse-panic-room.html) — subject-specific revision missions, focus sprint, flip cards, viva quiz, and pep talks.
- [Neural Network 3D Model](https://smirzaa36.github.io/bserc-project-2-html-pages/neural-network-3d-model.html) — rotate and zoom a network, inspect neurons, change its architecture and input pattern, animate a forward pass, and train one illustrative step.
- [Agent Autonomy Arena](https://smirzaa36.github.io/bserc-project-2-html-pages/agent-autonomy-arena.html) — choose a mission and priorities, compare four fictional agent profiles, inspect permissions, and save comparisons.
- [Prompt Injection Escape Room](https://smirzaa36.github.io/bserc-project-2-html-pages/prompt-injection-escape-room.html) — solve fictional AI-safety scenarios with choices, hints, scoring, and a safety checklist.
- [GPU Detective](https://smirzaa36.github.io/bserc-project-2-html-pages/gpu-detective.html) — explore training settings with a live VRAM map, illustrative memory estimate, diagnosis, and suggested fixes.

## How to use

Open any HTML page in a current browser. The pages are self-contained and designed to work offline. Use the Light/Dark switch at the top of a page; each page remembers the selected theme locally.

## Accuracy and privacy

Agent-fit scores and GPU figures are illustrative teaching simulations, not actual agent evaluations or hardware benchmarks. The neural-network output and training step are illustrative, not real model training. Escape-room content is fictional. The pages do not send data to a service. CSE study progress is stored in browser storage on the device.

## Project files

The repository includes five final HTML pages, this README, and [prompts.txt](prompts.txt), which contains the build prompts, refinement prompts, and effort-comparison notes. Keep private material, passwords, API keys, and restricted course content out of public copies.
